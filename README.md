# Gautam Kanna Kannapiran — Portfolio

This is my personal portfolio. I built it with plain HTML, CSS, and JavaScript, with no frameworks and no build step.

## What's here

- `index.html`: all of the content
- `css/style.css`: my styling and animations
- `js/script.js`: the interactive effects
- `assets/`: my résumé and Eightcap certificate

## How I host it

I push this folder to a GitHub repository and publish it with GitHub Pages. The live site is https://gautam-kanna.github.io/gautam-portfolio/

## Updating it

I edit the text in `index.html`, and I swap in a new résumé PDF in `assets/` when my experience changes.
